# minicorp-it-lab

VMware 기반 가상 회사 IT 인프라 구축 프로젝트

## 🎯 Project Goal

실제 기업의 IT 인프라 환경을 가상으로 구축하고 운영하면서
Windows Server, Active Directory, 네트워크, 보안 및
장애 대응 역량을 향상시키는 것을 목표로 한다.

## 🖥️ Environment

- VMware Workstation
- Windows Server
- Windows 11
- Active Directory
- DNS
- DHCP
- Group Policy
- PowerShell

## 🏢 MiniCorp

가상의 중소기업 MiniCorp의 IT 인프라를 구축한다.

### Departments

- Management
- Sales
- Engineering
- HR
- IT
